# فایل چاپ برچسب چادرها (ساتن)

برچسب‌های دوختنی برای ۱۰۰۰ چادر، با نام «حرم مطهر شاهچراغ» بالا، QR وسط و شناسه‌ی چادر پایین.

## فایل‌ها (پوشه‌ی `output/`)

| فایل | کاربرد |
|---|---|
| `chador-labels-print.pdf` | **فایل اصلی چاپ.** وکتور، متن به منحنی تبدیل شده (نیازی به نصب فونت نیست). |
| `chador-labels-cutguide.pdf` | خطوط برش هر برچسب، هم‌اندازه‌ی فایل چاپ (برای برش لیزری/حرارتی). |
| `chador-labels-proof.pdf` | پیش‌نمایش برای بررسی: چاپ + خط برش (قرمز) + محدوده‌ی امن دوخت (آبی). **چاپ نشود.** |
| `tent_ids.csv` | فهرست همه‌ی شناسه‌ها با ردیف/ستون روی ورق؛ برای وارد کردن به سامانه. |

## مشخصات فنی

- **اندازه‌ی ورق:** عرض ۱۰۰ سانتی‌متر × طول ۱۴۹٫۲ سانتی‌متر، مقیاس ۱۰۰٪ (**Scale نکنید**).
- **چیدمان:** ۲۹ ستون × ۳۵ ردیف = **۱۰۱۵ برچسب** (۱۰۰۰ چادر + ۱۵ یدک).
- **اندازه‌ی هر برچسب:** ۳۲ × ۴۰ میلی‌متر، با فاصله‌ی ۲ میلی‌متر بین برچسب‌ها برای برش.
- **فاصله‌ی مجاز دوخت:** ۴ میلی‌متر از هر لبه. هیچ چاپی در این حاشیه نیست و دوخت باید داخل همین حاشیه انجام شود.
- **شناسه‌ها:** `CH-000001` تا `CH-001015`. محتوای QR دقیقاً همین متن است.
- **QR:** نسخه‌ی ۱ (۲۱×۲۱ ماژول)، تصحیح خطای سطح H (حدود ۳۰٪)، اندازه‌ی ۱۸ میلی‌متر (هر ماژول حدود ۰٫۸۶ میلی‌متر) با حاشیه‌ی سفید حدود ۳ میلی‌متر دور آن.
- **رنگ:** فقط مشکی K=100 (بدون ترکیب رنگ)، زمینه‌ی سفید (بدون چاپ).
- **علامت برش:** در چهار گوشه‌ی شبکه و یک خط توضیح در حاشیه‌ی پایین (خارج از برچسب‌ها).
- **فونت:** وزیرمتن (Vazirmatn Bold)، مجوز OFL.

## نکات برای چاپخانه

- چاپ روی **ساتن مات پلی‌استر ۱۰۰٪** با روش دیجیتال/سابلیمیشن.
- اگر دستگاه نیاز به **آینه** دارد، خود چاپخانه آینه کند؛ فایل ما آینه نیست.
- برش با **لیزر یا چاقوی حرارتی** تا لبه‌ها نخ‌کشی نکند. فایل `cutguide` را بدهید.
- قبل از چاپ کامل، یک **نمونه‌ی کوچک** (چند ردیف) چاپ و اسکن کنید.
- بعد از چاپ، چند برچسب را با گوشی اسکن کنید و **آزمایش شست‌وشو** (۳۰ بار) انجام دهید.

## ساخت دوباره‌ی فایل‌ها

```
pip install segno reportlab fonttools uharfbuzz
python3 generate_labels.py --tents 1000
```

اندازه‌ها، حاشیه‌ی دوخت و متن بالا در بخش ثابت‌های بالای `generate_labels.py` قابل تغییر است.
